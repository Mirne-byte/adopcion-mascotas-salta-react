# 🐾 Huellitas de Amor

## Refugio de Adopción de Mascotas en Salta

Huellitas de Amor es un proyecto web desarrollado con React que busca facilitar la adopción responsable de mascotas.

### Características

- Inicio con presentación del refugio.
- Catálogo de mascotas disponibles para adopción.
- Filtros por especie, tamaño y edad.
- Formulario de contacto.
- Navegación entre secciones.
- Integración con imágenes de mascotas.

### Tecnologías utilizadas

- React
- JavaScript
- HTML5
- CSS3
- React Router
- EmailJS
- GitHub Pages

### Instalación

```bash
npm install
npm start
```
